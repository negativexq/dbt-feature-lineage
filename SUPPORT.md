# Support

dbt-feature-lineage is an open-source project maintained on a best-effort
basis — there's no guaranteed SLA or commercial support.

## Getting help

- **Reproducible bugs**: open a [bug report](https://github.com/negativexq/dbt-feature-lineage/issues/new?template=bug_report.yml).
- **Feature requests**: open a [feature request](https://github.com/negativexq/dbt-feature-lineage/issues/new?template=feature_request.yml).
- **Anything else** (usage questions, unclear behavior, etc.): a regular [GitHub issue](https://github.com/negativexq/dbt-feature-lineage/issues) is fine.

When asking for help, please include:

- The dbt-feature-lineage command you ran (or which Streamlit page and action).
- Whether the project was in manifest mode or static-analysis mode (see the README).
- Your dbt Core and Python versions, if relevant.
- A minimal reproduction — a small model SQL snippet or project structure, rather than a link to a large private repo.

See [SECURITY.md](SECURITY.md) instead if you're reporting a security issue rather than asking for help.
